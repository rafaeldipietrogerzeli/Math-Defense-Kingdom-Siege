# Math-Defense-Kingdom-Siege
Math Defense: Kingdom Siege é um jogo educativo onde cálculos mentais protegem o castelo contra hordas de inimigos. Resolva expressões matemáticas, para avançar por quatro fases com dificuldades crescentes. Desenvolvido com HTML, CSS e JavaScript puro, inclui geração procedural de desafios matemáticos, áudio sintetizado pela Web Audio API.
